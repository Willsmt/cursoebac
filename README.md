# 📚 Curso EBAC — Exercícios

Repositório de exercícios da minha formação Full-Stack na EBAC. Cada exercício vive em uma **branch própria**, isolada por tecnologia, para que dê para acompanhar a evolução do curso passo a passo e ver exatamente qual stack cada etapa valida.

> 🌐 Deploy: [cursoebac.vercel.app](https://cursoebac.vercel.app)
>
> ## 🗂️ Como navegar
>
> Cada branch abaixo é uma etapa independente. Clique no nome para abrir o código daquela branch.
>
